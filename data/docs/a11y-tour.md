# 空間導覽（給用讀螢幕、鍵盤的你）

想像你站在楚河渡口棋鎮：上方是星槎入口，左岸茶肆，右岸學習，橋上有石桌可下棋。進入園子後，你坐在桌前，棋盤在正前方，對手在對面。

這份說明把「象棋千秋」的畫面用文字畫成一張地圖：每一頁長什麼樣子、東西放在左邊還是右邊、從一處怎麼走到另一處。方位一律照你拿著手機、面對畫面來說：上＝遠處，下＝近處，左、右＝畫面的左右。

## 先打開「讀屏與鍵盤模式」

- 每一頁最前面都有一顆隱藏按鈕「♿ 開啟讀屏與鍵盤模式」，讀螢幕第一個就會摸到；也可以到設定房間的 🔒 小鎖匣 → ♿ 無障礙打開。
- 開了以後：下棋一律用平面棋盤（不畫 3D 園子），每一格都念得出來；每走一步都念出來；裝飾動畫關掉。
- 換頁時會念「頁面：」加頁名，例如「頁面：棋譜」。要等一陣子的東西（象棋引擎、資料、這一頁的圖）超過一秒還沒好，會先念載入的提示，好了再念「載入完成」。
- 隨時按 **?** 鍵聽鍵盤說明，說明卡裡有「🧭 空間導覽」（就是這一份）；按 **G** 鍵也能直接打開這份。
- 隨時按 **W** 鍵聽「我在哪裡」：目前頁面、焦點停在哪顆按鈕；在下棋的頁面再加輪到誰、選了哪顆棋、上一步；有地圖的頁面最後念「本頁地圖」。
- 第一次進到首頁、茶肆、大廳、學習、棋譜庫、下棋的頁面時，念完頁名會多念一句「本頁地圖」（只念給讀螢幕，畫面上不加字），內容就是下面各段的縮短版。

## 每一頁都一樣的骨架

1. **最上面的頂欄**：最左邊是「‹ 返回」（會寫要回到哪裡，例如「‹ 回渡口」），中間是頁名，最右邊是這一頁的小圖示按鈕（例如 🏠 回首頁、⛵ 回星槎）。
2. **中間的主畫面**：多半是一張滿版水墨圖，圖上的入口是一顆顆按鈕，標籤只有大字。
3. **最下面的導覽列**（首頁和幾個大頁才有）：由左到右「🏠 首頁、🌐 線上、📚 棋譜、⚙️ 設定」。

讀螢幕往右滑、或按 Tab，就是照「返回 → 頁名 → 右上圖示 → 圖上的入口 → 圖下面的卡片 → 底部導覽列」的順序走。卡片或確認框開著時，Tab 只在卡片裡面繞，按 Esc 關掉，焦點會回到原本那顆按鈕。

## 首頁：楚河渡口棋鎮

想像一張直立的水墨畫，一條河（楚河）從畫面上方流到下方，把畫面切成左岸和右岸，河上有一座石拱橋。

- **上方正中間，河上**：⛵ **雲河星槎**（一艘船）。上船可以去十三個朝代，園子、驛站、擂台都在船靠岸的渡口。
- **左上，左岸的巷口牌坊**：⚔ **對戰**。名字會跟著船停的朝代變：經典世界叫「觀星閣」，五代、元叫「茶肆」，宋叫「茶坊」，明叫「茶樓」，清叫「茶館」，秦漢叫「酒肆」。下面都叫它「茶肆」。
- **右上，右岸的書院山門**：📚 **學習**。經典世界叫「藏譜石窟」，宋以後叫「書院」。棋譜庫在這裡面。
- **左邊中段，橋頭告示牌**：📜 **今日推薦**，點了從下面拉出「今天的路」卡片。
- **正中間，橋上廣場的石桌**：👥 **身邊同桌**，兩個人用同一支手機面對面下。
- **畫面最下面的大按鈕**：♟ **快速對局**（馬上跟電腦下一盤，不算段位）。第一次下棋的人會看到「🔰 立即開始」。

Tab 的順序：雲河星槎 → 對戰 → 學習 → 今日推薦 → 身邊同桌 → 快速對局 → 底部導覽列。

## 茶肆（對戰）：一座兩層樓的茶樓

從首頁點「⚔ 對戰」進來，你站在茶樓的天井（中庭）。

- **正中間的八仙桌**：**線上對戰**，也就是「大廳」。
- **左下方的桌子**：**挑戰電腦**（跟象棋 AI 下，可以選強弱）。
- **左邊最下面、放棋盒的那張桌子**：**同桌對弈**（同一支手機兩人下）。
- **二樓左邊的廂房**：**車輪戰**（一個人同時下好幾盤）。
- **二樓中間的說書台**：**千秋盃**（每週六下午的 16 強擂台）。

Tab 的順序：線上對戰 → 挑戰電腦 → 千秋盃 → 車輪戰 → 同桌對弈。想回首頁按頂欄的「‹ 返回」或 🏠。

## 大廳（線上對戰）

從茶肆的八仙桌進來，或按底部導覽列的「🌐 線上」，兩條路都到同一個地方。

- **上面一張大廳的圖**：正中間是 🎲 **隨機配對**（一按就幫你找對手）；右上是 📜 **名冊**；左邊是 📺 **AI 對戰**。
- **圖下面由上到下**：千秋盃卡片 → 「正在對戰」的棋局（每一盤都可以按「觀看」）→ 「線上棋友」名單（點一位可以看他的資料、邀他下一盤）。
- 有人邀請你時會跳出確認框，焦點會自動移進去。

## 學習頁與棋譜庫

從首頁點「📚 學習」進來，你站在書院（或石窟）的前院，越往上越深。

- **最近的地方（畫面下方）**：左下 **象棋規則**、右下 **新手訓練營**。
- **中段**：左邊 **一盞茶殘局**、右邊 **錯棋重練**、最右邊 **主題訓練**；左邊牆上 **我的戰績**。
- **正中間的講台**：**棋力測驗**；右上一點是 **我的開局**。
- **最裡面（畫面上方）**：正中間的藏書閣是 📚 **棋譜庫**，再往上的小亭是 **猜著法**。

Tab 的順序：象棋規則 → 新手訓練營 → 一盞茶殘局 → 錯棋重練 → 主題訓練 → 棋力測驗 → 我的戰績 → 我的開局 → 猜著法 → 棋譜庫。

**棋譜庫**也可以直接按底部導覽列的「📚 棋譜」。裡面是一間書房：

- **左上**：🖼 **特級大師**（大師的生平）。
- **右上**：📦 **比賽對局**；**右邊中段**：🏆 **大師對局**。
- **下方正中間**：📖 **繼續研究**（上次看到哪裡）；**右下**：📒 **我的對局**。

## 園子：坐在石桌前下棋

園子在雲河星槎靠岸的渡口旁邊，路線是：

1. 首頁 → 上方正中間 ⛵ **雲河星槎**（星槎頁：航線、下船）。
2. 按「⚓ 下船」→ **渡口**。渡口有三扇門：🌳 **園子**、🏮 **驛站**、🏯 **擂台**。
3. 按「🌳 園子」→ 走一小段路的過場 → 坐到石桌前開始下棋。
4. 想換朝代：星槎頁的 🪨 **千秋石枰**，桌上擺著十三顆朝代石頭，點一顆就開往那一朝、直接進那裡的園子。

園子、驛站、擂台頂欄的「‹」都回渡口；渡口的「‹」回星槎；右上 ⛵ 也回星槎。

### 3D 園子長什麼樣子

一般模式下，園子是一個可以轉頭看四周的 3D 場景。你坐在石桌的這一側，棋盤擺在桌上：

- **正中間**：下棋的桌子，桌上有茶杯。
- **桌子對面**：對手（電腦對手、路人棋友或線上棋友）。
- **桌子左右兩邊**：凳子。**對手後面**：一張長椅或坐榻。
- **左右兩邊的立柱上**：燈籠。**四周**：兩種樹。**很遠的地方**：那個朝代的風景（長城、運河、江南水鄉……）。

### 讀屏模式：用「園子地點清單」代替 3D

讀屏模式以「園子地點清單」替代 3D 場景探索：不畫 3D 園子，改用平面棋盤；目前提供園子裡可以點的重點地點介紹，不是 3D 場景裡每一樣東西都能逐一摸到：

- 在下棋的頁面，**棋盤前面**有一顆「🌳 園子地點清單」按鈕（平常看不到，用 Tab 或讀螢幕摸到時才出現），後面接著「讀出盤面」，再來才是棋盤。
- 也可以按 **?** 鍵，說明卡裡有「🌳 園子地點清單」。
- 清單照由近到遠排：你的角色 → 正中間的桌子 → 桌上的茶杯 → 對面的對手 → 左右的凳子 → 對手後面的長椅 → 燈籠 → 兩種樹 → 遠方的風景。點一項＝在 3D 園子裡點那樣東西：跳出介紹卡，有時候會找到寶物（例如掀開茶杯找到一份棋譜）。

3D 園子裡「拖曳轉身、兩指縮放、切換俯視和平視」這些看風景的操作，在讀屏模式沒有對應的做法；下棋本身不受影響。

## 棋盤上的方位

- 棋盤是 9 路（直的）× 10 排（橫的）。每一格念成「紅方 炮，八路，第三排」：**路**是從你右手邊數過來（一路在最右、九路在最左），**排**是從你這一邊數過來（第一排最靠近你）。翻轉棋盤（你執黑）時一樣照你看出去的方向數。
- 鍵盤：**B** 跳到棋盤，方向鍵在格子之間移動，**Enter** 或空白鍵選子、再按一次落子；**R** 讀出整個盤面，**S** 讀狀態和棋鐘，**M** 讀上一步，**W** 我在哪裡。
- 鍵盤停在棋盤上的那一格，除了黃黑框，四邊各有一個指向格心的黃色三角形（看形狀也找得到，不只靠顏色）。
- 打開「🎧 聲音方位與動作提示音」（讀屏模式預設打開）後，戴耳機聽：以左右聲像提示棋子在第幾路——右邊的子偏右耳、左邊的子偏左耳、中路在正中間；翻轉棋盤跟著翻。聲音只分左右，沒有前後遠近，不是 3D 環繞；要知道確切位置還是聽念出來的「八路，第三排」。
- 選子、落子、吃子、將軍、走不了、輪到你、對方走完各有不同的聲音；你的時間剩 1 分、30 秒、10 秒是很高的嗶嗶兩聲，時間到是粗啞往下的兩聲（後一聲拉長）。吃子、將軍、時間快到、超時除了聲音也會念出文字（將軍和超時會插話先念）。
- 設定房間的 🔒 小鎖匣 → ♿ 無障礙 有「🔈 試聽左右」和「🎼 音效圖鑑」（九種聲音一個一個按 ▶ 試聽，另有左、中、右試聽）。音量跟著手機音量，App 裡沒有另外的音量；iPhone 靜音鍵打開時仍會響，要安靜請關掉「走子音效」「吃子音效」。

## 還不完整的地方

- 這份導覽是照程式裡的入口位置寫的，**還沒有在 iPhone VoiceOver、Android TalkBack 實機走過一遍**（VoiceOver 實機待 iOS 版），**也還沒有請視障玩家實際試用**；如果念的順序跟這裡寫的不一樣，請用設定裡的「意見回饋」告訴我們。
- 圖上入口的名字會跟著朝代換（茶肆、茶樓、書院……），位置不變。
- 星槎甲板、渡口、驛站各頁的細部位置這份還沒寫進來，那幾頁都是一般的按鈕列表，照 Tab 順序走就可以。
