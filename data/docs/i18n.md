# 英文介面與語言架構（2026-11-13，評比第 14 輪 F1）

English summary: the app now has an English UI layer. Open **Settings ⚙ → 🌐 (top right)** and pick **English**. The main flow is in English: the tab bar and top bar, a quick game against the computer (new-game menu, opponent cards, the game page, status line, move list, resign and undo confirmations, the result window) and the main settings. Moves are shown in **WXF notation** (for example `C2.5`, `H8+7`). Story text, character dialogue and these guides stay in Chinese for now. Translation reports are welcome through 💬 Feedback; the public repository does not accept pull requests.

預設仍是繁體中文，**不會自動切換**。手機系統是英文、又還沒選過語言的人，開 App 後會看到一次小提示「English UI: Settings ⚙ → 🌐」，要不要換由自己決定。

## 1. 怎麼切換

- 設定頁頂欄右邊的 🌐：繁體中文、簡體中文、English 三選一（按鈕上的語言名稱各用自己的文字，簡體那顆寫簡體字，看不懂中文的人也認得出 English）。
- 設定 → 🖌 字體 →「文字」那一排：同樣三個選項。
- 換語言會重新載入一次畫面（跟原本的繁簡切換一樣），對局、存檔都不受影響。
- 選 English 時，繁簡模式一律回到繁體（英文字典是照繁體原文對的）；從 English 切回繁體或簡體，英文層整個不裝，畫面跟原本一模一樣。

## 2. 架構

程式在 `m/07i18n.js`（前綴 `i18n`、`I18N_`），做法是「掃描畫面上的文字節點，查字典換成英文」，**不改各頁的畫面程式**：

1. **字典** `I18N_EN`：繁中原文 → 英文，約 350 筆；另有近 40 條句型。鍵是畫面上那段字去掉前後的圖示與全形標點（♟、👉、！、？、…會自己保留成英文標點）。
2. **句型** `I18N_PAT`：有數字、名字的動態句子用正規式組英文，例如「第 3 級」→ Level 3、「紅方稍好，約領先 1.5 個兵」→ Red slightly better, ahead by about 1.5 pawns、「積分 +16 → 216 分」→ Rating +16 → 216 pts。
3. **切段**：整句查不到，就照中文標點（，、；・：。！？（）「」）切開逐段翻，再接回英文標點。
4. **整句才換**：只要還剩一個中文字，那一段就**整段不換**，畫面上不會出現半中半英的句子。
5. **監看**：選了 English 才裝 `MutationObserver`，新出現的畫面、改過的字、`aria-label`／`title`／`placeholder` 都會過一遍。原文記在 `WeakMap`，`i18nRevert()` 可以原封不動換回來（只還原「現在還是我們換上去的那段英文」的地方）。
6. **不動的地方**：棋盤 SVG（棋子上的字）、頭像圓章（只放得下一個字）、輸入框、程式碼、語言選項本身（`data-nocc`）、特別標 `data-noi18n` 的元素。
7. **保留字** `I18N_GUARD`：有幾個模組用畫面上的字找段落（隱私、官階、進階、下船、上星槎、估計棋力、正在對戰、取代這支手機），這幾個字刻意不翻，測試會檢查。
8. **其他**：`<html lang>` 跟著換（en、zh-Hant、zh-Hans），標題改成 Xiangqi Qianqiu；數字與日期有 `i18nNum()`、`i18nDate()`（英文 1,234、Nov 13, 2026；中文 2026/11/13）。

## 3. 英文記譜：WXF

畫面上的著法（著法條、提示、結果）用 WXF 記譜，讀螢幕念完整英文：

| 中文 | WXF | 讀螢幕念法 |
|---|---|---|
| 炮二平五 | C2.5 | Cannon 2 traverses to 5 |
| 馬8進7 | H8+7 | Horse 8 advances to 7 |
| 車1進3 | R1+3 | Chariot 1 advances 3 |
| 相三進五 | E3+5 | Elephant 3 advances to 5 |
| 前俥平五 | +R.5 | Front Chariot traverses to 5 |
| 後馬退七 | -H-7 | Rear Horse retreats to 7 |

- 字母：K General（帥／將）、A Advisor（仕／士）、E Elephant（相／象）、H Horse（傌／馬）、R Chariot（俥／車）、C Cannon（炮／砲）、P Soldier（兵／卒）。
- 動作：`+` 進（advances）、`-` 退（retreats）、`.` 平（traverses）。直走的子（車、炮、兵、帥）進退寫步數，斜走的子（馬、相、仕）寫目的那一路。
- 路數照各方自己的右邊數起（紅方中文用一到九、黑方用 1 到 9，WXF 都寫阿拉伯數字）。
- 同一路有兩顆一樣的子：不寫原來那一路，在字母前面加 `+`（前）、`-`（後）；三顆時中間那顆用 `=`。
- 讀螢幕的每一步：「You: Cannon 2 traverses to 5」「Computer: Horse 8 advances to 7; your move」，吃子、將軍、將死接在後面（captures Black Horse, check, checkmate）；棋盤格子念「Red Cannon, file 8, rank 3」。

## 6. 怎麼加新的翻譯或新語言

- **補一句英文**：在 `I18N_EN` 加一筆「繁中原文：英文」；有數字或名字的句子在 `I18N_PAT` 加句型。原文要跟畫面上的字一模一樣（前後的圖示、！？可以不寫）。
- **加新語言**（例如日文）：照 `I18N_EN` 再做一份字典，`i18nLang()`／`i18nPick()` 多認一個語言代號，設定的語言選項多一顆按鈕；架構（掃描、切段、還原、讀螢幕）不用改。
- **測試**：`node --test xiangqi-lab/tools/test-i18n.js`。測試會從原始碼切出主流程每一段固定的字，檢查都翻得出英文；也會用假 DOM 畫一頁對局，切英文後看不到中文、切回繁中一字不差。
- 新增保留字（別的模組要用畫面上的字找東西）時，加進 `I18N_GUARD`。

## 7. 回報翻譯問題

看到翻錯、太長被切掉、或某一頁還是中文，歡迎從 💬 回報問題（意見回饋）告訴開發者，寫清楚是哪一頁、原本的字。原始碼公開在 GitHub 的 source/，依 GPL-3.0-or-later 授權；這個倉庫不收 PR（pull request），翻譯一律由開發者整理後放進字典。
