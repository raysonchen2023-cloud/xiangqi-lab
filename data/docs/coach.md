## 一、棋譜匯出

### 怎麼匯出
1. 打開一盤棋（人機、真人、研究、古譜、大師對局都可以），按右上角 **📤 匯出棋譜**。
2. 選格式：
   - **PGN（通用格式）**：象棋 PGN，記法用 ICCS（`H2-E2`）。象棋巫師等支援象棋 PGN 的軟體都能打開。
   - **中文記譜（純文字）**：炮二平五　馬8進7……每回合一行，適合直接貼到 LINE、Email 給教練。
3. 「附上評等與 Pikafish 評語」打勾：每步的評等（正著、妙著、緩著、失著、敗著）、不好的棋 Pikafish 建議怎麼走、少了約幾個兵、走完後的局面，都寫成 PGN 的 `{註解}`（文字版寫在【】裡）。
4. 送出：**📤 分享**（手機的分享選單，能傳檔案就傳 .pgn／.txt 檔）→ 沒有分享功能就 **📋 複製** → 再不行就 **⬇ 下載**檔案。
5. 對局紀錄頁可以一次匯出目前篩選的對局（最多 100 盤），一份 PGN 裡多盤棋。

### 匯出規則
- **主線**＝目前看的這一條著法（主線，或正在看的變著）。**變著**（第 11 輪起）：這盤其他的分支（古譜書上的變著、存檔時分出去的支線），還有檢討頁正在看的「自由走棋」或「Pikafish 推演」，都寫成變著，可以一層包一層。匯出視窗有變著時多一個「附上變著（分支）」勾選，預設打勾。
  - PGN：照 PGN 標準寫在被取代的那一步後面，用 `( … )` 括起來，變著裡也可以有 `{註解}` 和下一層 `( … )`；變著從同一個回合數開始，黑方那步寫 `1...`。例如 `1. H2-E2 (1. C3-C4 H9-G7) 1... H9-G7 (1... B9-C7 2. H0-G2 (2. B0-C2)) 2. H0-G2 I9-H9`。
  - 中文記譜：主線照舊每回合一行，後面多一段「【變著】」，一段一行：`變著 1（第 1 步起，紅方改走）：1. 兵七進一　馬8進7`、`變著 2（第 2 步起，黑方改走）：1. ……　馬2進3　2. 傌二進三`，下一層標 `變著 2-1`。
  - 同一步、同一個走法的分支只寫一次；自己的對局照樣不帶留言，變著也一樣。
- 起始局面不是標準開局（殘局、石桌往事從中局開始的關）才寫 `[FEN "… w - - 0 1"]`；黑方先走時第一步寫 `1...`。
- 結果：紅勝 `1-0`、黑勝 `0-1`、和 `1/2-1/2`、中止或進行中 `*`。
- **隱私**：只有棋手的顯示名稱（「你」換成自己的暱稱）；名字裡夾帶的 `#代號`、`（ID：…）` 會拿掉；不含玩家 ID、裝置代號、匿名代號。自己的對局（人機、真人）**不帶對局中的留言**；古譜、大師對局才帶書上的批註。
- 標頭的引號、反斜線照 PGN 規則跳脫；註解裡的大括號換成全形括號，換行變空格，其他軟體不會讀壞。

### PGN 範例（附評等）
```
[Game "Chinese Chess"]
[Event "挑戰電腦"]
[Site "象棋千秋"]
[Date "2026.11.11"]
[Round "-"]
[Red "小明"]
[Black "幻影棋客・晉級賽（業2）"]
[Result "1-0"]
[Format "ICCS"]
[Annotator "象棋千秋賽後評等（Pikafish）"]

1. H2-E2 {正著；走完後紅方稍好} 1... H9-G7 {正著；走完後均勢，雙方差不多} 2. H0-G2 {正著；走完後紅方稍好} 2...
I9-H9 {正著；走完後均勢，雙方差不多} 3. I0-H0 {妙著；走完後紅方稍好} 3... B9-C7 {正著；走完後紅方稍好} 4. B0-C2
{緩著；Pikafish 建議 俥九平八；差約 0.6 兵；走完後均勢，雙方差不多} 4... C6-C5 {正著；走完後均勢，雙方差不多} 1-0
```
不勾「附上評等」時就是乾淨的 `1. H2-E2 H9-G7 2. H0-G2 I9-H9 …`。

### 中文記譜範例
```
【小明 對 幻影棋客・晉級賽（業2）】
紅方：小明　黑方：幻影棋客・晉級賽（業2）
賽事：挑戰電腦
日期：2026.11.11

1. 炮二平五【正著】　馬8進7【正著】
2. 傌二進三【正著】　車9平8【正著】
3. 俥一平二【妙著】　馬2進3【正著】
4. 傌八進七【緩著・建議 俥九平八】　卒3進1【正著】

結果：紅方勝（將死）（1-0）
（象棋千秋匯出）
```

### 為什麼不做 XQF
XQF 是象棋演播室系列的**二進位**格式：檔頭有版本、加密金鑰，每一步的座標要照金鑰做位移編碼，版本 1.0～1.2 的規則還不一樣，註解要另外算長度。做得出來，但要寫一套二進位編碼器加上跟實際軟體互讀的測試，成本高。
PGN 已是業界通用的交換格式，多數象棋軟體都能讀；真的需要 XQF，可以用象棋軟體打開 PGN 再另存成 XQF。

### 還沒做
- 匯入 PGN（P17.2 的「匯入」）：還沒有。
- 變著一起匯出：第 11 輪已做（見上面「匯出規則」）。匯入時 PGN 的 `( … )` 和中文記譜的「【變著】」都讀得回變著樹，但「我的研究」存檔只能存一條主線，變著會抄成文字放在第 0 步的開頭說明，還不能在檢討頁點進去走。

## 二、殘局戰術主題分類

### 怎麼標
`node xiangqi-db/tools/canju/10_themes.js`（約 45 秒）：替一盞茶殘局 621 題每題寫新欄位 **`th`＝[主題…]**，檔頭加 `byTheme`（各主題題數）、`thGroups`（分組）、`thNote`（說明）。**原本的欄位一個都不動**。
兩份都寫：`xiangqi-db/art/canju/canju-set.json`（原始檔）、`xiangqi-lab/site/data/canju/canju-set.json`（網站）。`tools/canju/4_build.js` 重建題庫後會自動再跑一次。

只用走法規則（`site/core.js`），不跑引擎、不猜：
1. **照主變**（應著樹第一條：解題方的正解、對方最頑強的應法，一路到底再接示範）用 `tools/canju/8_tags.js` 的 tagsOf：連將、安靜一手、棄子（走到對方吃得到的格子而且對方真的吃了）、一子攻雙（→ 捉雙）、以少勝多、殺棋／困斃，以及**最後一步的殺型**（重炮、馬後炮、臥槽馬、掛角馬、鐵門栓、雙車錯、雙將、悶宮）。
2. **第一步**用 `tools/tag_tactics.js`（主題訓練 quiz.json 用的同一套）：將軍、抽將、捉雙、閃擊、牽制、引離（殺棋題不另外算捉雙、閃擊、牽制）。
3. 題庫原本的 `kill`（車殺、炮殺、馬殺、小兵擒王…）併進來；已經有具體殺型時，不再掛籠統的「車殺／炮殺／馬殺」。
4. 主變走完沒有將死也沒有困斃＝**保勝**（一步定勝負、大師收官裡只求保住勝勢的題）。守和、解殺照題目的 `hold`／`def`。

### 殘局頁「依主題選題」
🍵 一盞茶殘局 → 自由練習下面的 **依主題選題（殺法、戰術）**：每個主題寫「解過／題數」。點一個主題 → 清單由易到難（✔＝解過），可以挑一題，或按「▶ 依序練」從還沒解的開始；這樣進去的題，解完「下一題」會接同一個主題（store `cjTh`）。按上面的題型（一步定勝負、短殺…）就回到照題型出題。解完卡也會列出這題的主題。

### 古譜（書閣）

這 511 局在棋譜庫打開時，**ℹ 棋局資訊**會列出「一盞茶殘局・戰術主題」和「練這題 ›」。
棋譜庫的**清單**還不能依主題篩選：清單的資料是 `core.js` 的 summary 給的，只帶固定欄位；要改得動 `xiangqi-referee.js`（產生 core.js）和 `src/local.js`，這次沒動。沒收進一盞茶的古譜殘局，書上的著法沒驗證過（常有錯著），不硬標。

## 三、教練作業（最小版）

### 教練出作業
1. 🍵 一盞茶殘局 → **🧑‍🏫 教練出作業**（或打開 `#/hw`）。
2. 填作業名稱（例如「第 3 週・馬後炮」），在下面切換 **🍵 一盞茶殘局／🧠 主題訓練題**，用主題篩選（殘局：雙車錯、馬後炮…；主題訓練：將軍、殺棋、抽將、捉雙、閃擊、牽制、引離、悶宮），點題目加入（最多 20 題，可以 ↑ 調順序、✕ 移除）。選好的會記在這支手機（store `hwDraft`），換頁回來還在。
3. 按 **🔗 產生作業連結** → 📋 複製連結／📤 分享，傳給學生。可以先按「▶ 自己先試做」。

### 連結格式
`<App 網址>#/hw/<編碼>`，編碼＝`1`＋base64url（`標題|c:殘局題號,q:主題題號,…`）。全部在網址裡，不需要伺服器、不需要登入。
範例（馬後炮 3 題＋主題訓練殺棋 1 題）：
```
#/hw/156ysIDMg6YCx44O76aas5b6M54KufGM6bGsxNTYsYzptcjAwMyxjOnNxMjUzLHE6ZTE
```
解開是 `第 3 週・馬後炮|c:lk156,c:mr003,c:sq253,q:e1`。題號只收英數字、底線、點、減號；超過 20 題編碼時截掉、超過 30 題或格式不對的連結當成壞連結（畫面請學生找教練重傳）。

### 學生做作業
- 打開連結＝作業清單：每題名稱和狀態，按「▶ 開始作業」照順序做（也可以點任一題）。
- 殘局題用一盞茶的解題畫面（`#/canju/hw/<編碼>/<第幾題>`）：走錯會看到對方的反駁，可以退回重想；提示、看答案照舊。
- 主題訓練題（`#/hw/<編碼>/<第幾題>`）：找出最好的一步；走錯會退回去讓你再試，也可以看答案；直接將死也算對。
- 每題記：**第幾次答對**（走錯幾次＋1）、**用時**（第一次打開到答對）、有沒有看答案。答對後再亂走不會改成績。
- 做完回清單 → **📋 傳成績給教練**：可以填名字（選填，只放進複製的文字），按「複製成績」或「分享」，自己貼給教練。成績文字範例：
```
🧑‍🏫 作業成績：第 3 週・馬後炮（王小華）
完成 4／4 題・第一次就答對 2 題・看答案 1 題・總用時 6:42
1. 殘局・短殺〈…〉：第 1 次答對・1:05
2. 殘局・短殺〈…〉：第 3 次答對・2:47
3. 殘局・中殺〈…〉：看了答案（之前試了 2 次）
4. 主題・殺棋〈吃掉沒人保護的車〉：第 1 次答對・0:31
（象棋千秋・作業代碼 156ysIDMg6Y…）
```
- 成績只存在這支手機（store `hwRec`，最多留 20 份作業），**App 不上傳任何東西**；作業的殘局題也不送一盞茶平常的匿名校正資料。想重做按「↺ 清掉這份作業的成績重做」。


### 錯因分類與弱點追蹤（11/12 第 6 輪評比改善）
教練在「收成績」頁貼上學生成績後，表格每格多一行**錯因**，表格下面多一張「🔎 錯因與弱點」：
- **錯因只看學生傳來的四個數字**（做完沒有、走錯幾次、用時、有沒有看答案），不猜學生在想什麼：

| 錯因 | 判定 | 給教練的意思 |
|---|---|---|
| 一次就對 | 第 1 次答對、3 分鐘內 | 會了 |
| 想很久 | 第 1 次答對、超過 3 分鐘 | 會，還不熟 |
| 計算不穩 | 第 2～3 次才答對 | 方向對，算得不夠深或漏看一步 |
| 多次試錯 | 第 4 次以後才答對 | 比較像在猜，回頭看這個主題的基本型 |
| 不會解 | 看了答案 | 這個主題還沒學會 |
| 沒做完 | 打開過、沒答對也沒看答案 | — |

- **這份作業最弱的主題**：照題目的主題（殘局的殺法、主題訓練的標籤）算「沒一次答對」的人次比例，比例高的排前面。
- **每位學生的弱點**：把這支手機收過的所有作業合起來（同名字的學生算同一人），列出做了幾份作業、幾題、一次就對的比例、錯得最多的兩個主題。比例低的學生排前面。
- **CSV**：每題多一欄「錯因」；表格下面接著錯因統計、各主題弱點兩段，Excel／Google 試算表打得開。
- 程式：`m/10d-coach.js` 的 hwCause、hwTheme、hwWeak、hwGradeTab、hwCsv；行為測試在 `tools/test-coach.js`（錯因判定的每個邊界、跨作業合併、排序、CSV 欄位）。
- 一樣**不上傳**：全部只用教練手機上存的成績算。

## 四、測試與在瀏覽器驗

自動測試（不開瀏覽器）：`node --test xiangqi-lab/tools/test-coach.js`（17 項）：PGN 標頭、ICCS 著法、結果、FEN、黑先、註解跳脫、用一個簡單 PGN 解析器讀回再照規則重走局面一致；中文記譜；隱私（沒有 ID、裝置代號、對局留言）；主題規則（重炮殺、安靜一手保勝、kill 併入）、兩份題庫的 th／byTheme 一致而且原欄位都在；cjThNext；作業編碼解碼、壞連結、成績文字、hwXM；接線（m.html include、#/hw 路由、📤 按鈕）。

在瀏覽器驗（開發伺服器重開才吃到新的 m.html include）：
