# 色弱模式與色覺模擬掃描（2026-11-12，評比第 11 輪）

約有 8% 的男性、0.5% 的女性有某種紅綠色覺差異。象棋偏偏是「紅方對黑方」，App 裡的提示也常用綠（可走、上一步）對紅（將軍、失誤）。這一頁說明「色弱模式」改了什麼、怎麼用工具模擬色覺障礙來量，以及量不到的地方。

## 1. 色弱模式做了什麼

開關在 **設定**（存成 `cbMode`，預設關），切換後立刻生效，不用重新整理。原則是：**每一個靠顏色分辨的東西，都再加一個不靠顏色的記號**（形狀、文字、明暗），顏色本身也換成紅綠色盲分得清楚的「藍／橘」。

| 畫面上的東西 | 原本 | 色弱模式 |
|---|---|---|
| 紅子、黑子 | 只差字的顏色（紅字、黑字） | **黑子棋面外圈多一道粗黑環**（裡外夾白線），紅子不加：不看顏色也分得出是哪一方 |
| 可以走的空格 | 綠色小圓點 | **黃點黑邊**（任何棋盤上都明顯） |
| 可以吃的子 | 綠色圓圈 | **四角瞄準框**（形狀跟「上一步」的圓圈不同） |
| 上一步 | 綠色圓圈＋箭頭 | **朱橘色＋黑邊白邊兩圈**；跟電腦建議的**藍色**箭頭是紅綠色盲分得最開的一組 |
| 被將軍 | 紅色虛線圈 | 外圈加粗，將帥右上角加**黃底黑字「將」牌** |
| 評語妙著～敗著 | 金、綠、藍、灰、橘、紅字 | 加符號 **★ ✓ ○ △ ✗ ✗✗**；好的改深藍紫、壞的改深橘，字色對比 4.5:1 以上 |
| 賽後報告好棋／失誤 | 左邊金線／紅線 | 好棋實線＋「★」，失誤虛線＋「✗」 |
| 勝負、正招／失誤長條 | 綠對紅 | 藍對橘，失誤那段加斜紋，輸的小點改方形 |
| 形勢條 | 紅對黑 | 紅方那段加斜紋 |
| 輪到誰 | 名字變綠 | 名字前加「▶」；黑方頭像加黑框（跟黑子一樣） |
| 底欄目前那一格、推薦標籤、棋鐘快沒時間 | 只靠顏色 | 底線、「！」黃牌、「⚠」 |

已經開「高對比棋子」或「高對比主題」的人，棋盤原本就是黑子反白、黃點、瞄準框、「將」牌，色弱模式只再把上一步改成朱橘，不重複疊記號。

**3D 棋盤目前還沒跟著改**（色弱記號只做在平面棋盤）。需要的人可以在設定打開「專注棋盤模式」（只留平面棋盤）。3D 的改法已列成待辦，見第 5 節。

## 2. 怎麼量：用 Chrome 模擬色覺障礙

工具：`xiangqi-lab/tools/qa/colorblind-scan.js`（可以重跑，約 6 分鐘）。

- 一個無頭 Chrome（Chrome 156），手機尺寸 390×844、2 倍解析度。開頁前設定測試房（`xq_netRoot`），用全新的瀏覽器設定，不碰任何人的存檔；跑完瀏覽器和本機伺服器都關掉。
- 用 Chrome 開發者協定的 `Emulation.setEmulatedVisionDeficiency` 依序模擬：**紅色盲**（protanopia）、**綠色盲**（deuteranopia）、**藍色盲**（tritanopia）、**全色盲**（achromatopsia）、**視力模糊**（blurredVision），每一種都把色弱模式關、開各拍一次。
- **固定盤面**：用 App 自己的棋盤程式畫同一盤棋（紅方炮二平五之後，黑方選起砲：有可走的點、可吃的傌、上一步箭頭、電腦建議箭頭）。截圖後在圖上的固定位置取樣（字、棋面、外圈、圓點、箭頭），取中位數，再算 **WCAG 對比**（相對亮度公式，1:1～21:1）和 **ΔE 色差**（CIE76，大於 10 一眼分得出，小於 5 很難分）。模擬後的顏色是 Chrome 真的畫出來的像素，不是自己換算的。
- **主要頁面**（首頁、對局中、殘局、設定、雲河星槎）：每種模擬截圖；畫面上看得到、底色是純色的文字，用 computed style 的字色和底色、套同一組色覺模擬矩陣（Machado 2009）換算對比。
- **換算可信度**：固定盤面每一組都用「正常視覺取樣 → 矩陣換算」跟「Chrome 實際模擬」對照，36 組對比值平均只差 0.05～0.06、最大差 0.38，所以頁面文字用矩陣換算可以信。

怎麼讀：

- **紅黑兩方**：只靠字色時，紅色盲下紅字對黑字只剩 2.1:1、色差 39；全色盲下色差 35，而且是「深紅對黑」，小字很難分。色弱模式的黑環讓兩方外圈的對比從 1.1 變成 4.4～5.1（色差 49～63），**五種色覺都一樣分得開**，因為它靠的是明暗和形狀，不是色相。
- **可走的點**：原本綠點在木紋棋盤上只有 1.4～1.8:1；黃點黑邊是 6.9～7.6:1。
- **上一步**：朱橘本身對深色木紋只有 2.4～2.9:1，所以外面描了黑邊、白邊，外緣對比 9.9～11.7:1（非文字圖形的門檻是 3:1）。跟電腦建議的藍箭頭，紅、綠、藍色盲下色差都在 100 以上（原本 63～69，藍色盲只有 23）。
- **全色盲**下朱橘和藍的亮度差不多（色差 4），這時靠的是形狀：上一步有黑白外框、起點有虛線圈，電腦建議是沒有外框的藍箭頭，多步建議還有 1、2、3 號碼。
- **視力模糊**下所有細節都糊掉，黑環只剩 1.22:1，這是預期的：模糊要靠放大（設定 → 字級、專注棋盤模式），不是靠顏色。

## 6. 限制

- **模擬不等於真人。** Chrome 的模擬是「完全缺少某一種視錐細胞」（二色視）的數學近似，用的是 Machado、Oliveira、Fernandes 2009 的矩陣。實際上大部分色弱者是「部分缺少」（異常三色視），看到的介於正常和模擬之間；每個人的程度不同，螢幕、亮度、環境光也有影響。這份數字只能說明「最嚴重的情況下還分得開」，不能代替真人色弱玩家試用。之後會請色弱玩家實際試玩回饋。
- **取樣有誤差。** 固定盤面是在截圖上取一圈像素的中位數，棋子圖本身有紋理和陰影；換算對照最大差 0.38，表裡的數字大約有 ±0.4 的誤差。
- **壓在圖上的文字沒算。** 首頁、星槎等頁面很多字壓在水墨圖或漸層上，單用色碼無法算對比，這些只能看截圖；頁面文字的取樣數因此偏少。
- **只量了預設樣式。** 棋盤用預設的立體木紋＋古典棋子；其他朝代棋盤、棋子樣式的黑環、黃點是同一套畫法，但對比數字沒有逐一量。
- **全色盲**下朱橘和藍亮度相近，靠形狀分；**視力模糊**下色彩記號幫助有限，要靠放大字級、專注棋盤模式。
- 3D 棋盤還沒做（見第 5 節）。
