# 快棋模式與預走（2026-11-13，評比第 12 輪）

想下得快的人，最在意兩件事：電腦還在想的時候，自己能不能先把下一步排好；動畫和特效能不能少一點、別擋手。這一頁說明「預走」和「⚡ 快棋模式」怎麼用、規則、量出來的數字，以及還沒做到的地方。

## 1. 預走：電腦還在想，先把下一步排好

在挑戰電腦（含晉級賽、練功房、快速對局、石桌往事、錯棋重練）的**平面棋盤**上（朝代擂台一律在 3D 園子裡下，所以沒有預走）：

1. 電腦還在想（狀態列寫「🤔 思考中…」）時，點自己的一顆子，棋子照樣拿起來，棋盤標出可以排的落點。
2. 再點落點，就排好了。棋盤上會出現：**起點、落點各一個紫色虛線框**（落點框裡淡淡塗色）、中間一條**淡色虛線箭頭**、落點右上角一個**「預」字小牌**；狀態列變成「🤔 思考中…・⏳ 已預走「傌八進七」」。
3. 電腦一落子、輪到你的那一刻，App 先照棋規檢查這一步：
   - **合法**：馬上替你走出，不用再點。
   - **不合法**（被電腦剛走的子擋住、會被將軍、走法不成立）：自動取消，跳一句「↩ 預走「…」現在走不了，已取消」，輪到你自己下。
   - **那顆子被電腦吃掉了**：自動取消，跳一句「↩ 預走的那顆子被吃掉了，預走已取消」。
4. 預走走出以後 2.5 秒內，電腦剛剛那一步用**灰色虛線**標著（棋盤上的「上一步」已經換成你的預走，不標的話會看不到電腦走了什麼）。

取消與改選：

| 什麼時候 | 點哪裡 | 結果 |
|---|---|---|
| 已經排好預走 | 自己的另一顆子 | 取消預走，改拿起那顆子（可以馬上重排） |
| 已經排好預走 | 其他任何地方（空白、對方的子、原來那顆子） | 只取消 |
| 拿起子、還沒點落點 | 同一顆子、空白或不能排的地方 | 放下，不排 |
| 拿起子、還沒點落點 | 自己的另一顆子 | 改拿那顆 |

其他規則：

- **一次只排一步**。悔棋、開新局、對局結束、換到別盤，排著的預走都會自動清掉，不會走進別盤。
- **可以排的落點**照棋子的走法算，但「現在被對方的子擋住」不算擋（電腦這一步可能讓開）；被自己的子擋住照擋；落點不能是自己的子（點自己的子＝換一顆）。所以有些排得上的步，輪到你時可能不合法，這時就照上面的規則取消。
- 拖曳也可以排：電腦在想時把自己的子拖到落點放下，跟點兩下一樣。
- 開了「落子前再確認」時，排預走也要在落點點兩下（跟平常一樣），走出的那一刻不用再確認。
- 黑洞序局等有走法限制的關卡，預走走出時照樣由關卡規則把關。
- 螢幕報讀：排好、取消、走不了都會念出來。
- 開關：設定「⏳ 預走」（存成 `premove`，預設開，勾選框 id 是 `premoveSw`）。關掉就跟以前一樣，電腦在想時點棋盤沒有反應。

## 2. ⚡ 快棋模式：動畫最短、電腦不慢慢想

開關在設定「⚡ 快棋模式」（存成 `blitz`，預設關，勾選框 id 是 `blitzSw`），切換後立刻生效。打開時：

| 動畫 | 一般 | 快棋模式 |
|---|---|---|
| 走子滑動 | 0.28 秒 | 0.09 秒 |
| 被吃的子淡出 | 0.45 秒 | 0.12 秒 |
| 上一步外圈（延遲＋淡入） | 0.45 秒 | 0.14 秒 |
| 吃子水墨「吃」 | 1.4 秒 | 略過 |
| 將軍印章「將軍！」 | 2.1 秒 | 略過（被將軍的紅色虛線圈、語音「將軍」照舊） |
| 開局特效「開局」 | 2.5 秒 | 略過 |
| 開局名稱（中炮、屏風馬…） | 2.55 秒 | 略過 |
| 將死動畫（會擋住結果視窗） | 2.7 秒 | 略過，結果視窗直接出來 |
| 結果視窗彈出 | 0.28 秒 | 0.06 秒 |

電腦節奏：快棋模式打開時，電腦一律用「快速」節奏（每步約 1～1.5 秒），不管設定裡「電腦下棋節奏」選的是擬真；關掉快棋模式就照那個設定。

原本的規則照舊：系統開了「減少動態效果」、或開了專注棋盤／螢幕報讀模式時本來就不播的特效，照樣不播；設定裡個別關掉的動畫（動畫、吃子特效、將軍特效、開局名稱動畫）照樣關著。快棋模式只會讓動畫更短，不會把關掉的打開。震動、音效不受影響（震動另有開關）。

## 3. 量測結果

全部可以重現：在專案資料夾跑 `node xiangqi-lab/tools/blitz-measure.js 400`（固定亂數種子，不開瀏覽器）。以下是 2026-11-13 在開發電腦（Node v24.20.0）跑出來的數字。

### 3.1 預走反應時間

做法：用 Node 的 vm 載入預走模組，配一個照挑戰電腦畫面掛勾寫的假對局畫面（點選、重畫、送出、收到電腦落子事件後重新讀盤面，流程跟 App 一樣），棋規用 App 同一份。電腦隨機走合法步；每回合玩家在電腦思考時隨機排一步預走。400 回合裡：預走走出 329 次、不合法取消 68 次、子被吃取消 3 次。

| 量什麼 | 次數 | 平均 | 中位數 | 95% | 最大 |
|---|---|---|---|---|---|
| 電腦落子 → 畫面輪到你 | 400 | 0.2 毫秒 | 0.2 毫秒 | 0.4 毫秒 | 1.2 毫秒 |
| 電腦落子 → 送出預走 | 329 | 0.1 毫秒 | 0.1 毫秒 | 0.2 毫秒 | 0.9 毫秒 |
| 電腦落子 → 預走那步套到盤面 | 329 | 0.3 毫秒 | 0.3 毫秒 | 0.6 毫秒 | 1.4 毫秒 |

也就是：輪到你的同一瞬間，預走就已經走出，中間沒有任何計時等待（沒有 setTimeout），只有幾次非同步回呼。

注意：這是程式邏輯的時間，**不含手機重畫棋盤的時間**（規定不開無頭瀏覽器，量不到）。在手機上打開主控台輸入 pmvStats()，可以看到最近 20 次預走「電腦落子 → 送出預走」的真實毫秒數。

### 3.2 電腦思考時間（60 個固定局面，業級第 8 級）

| 節奏 | 平均 | 中位數 | 95% | 最長 |
|---|---|---|---|---|
| 擬真（預設） | 3007 毫秒 | 3011 毫秒 | 5683 毫秒 | 6213 毫秒 |

### 3.3 動畫縮短前後

第 2 節的表就是量出來的：開局名稱、將軍印章、開局特效、吃子水墨是把棋盤程式裡那幾個特效函式原樣拿出來在 vm 實跑（記下建了幾個畫面元素、幾毫秒後移除），快棋模式下一個畫面元素都不建；走子滑動等 CSS 動畫長度、將死動畫擋結果視窗的時間、結果視窗彈出的長度是從原始碼讀的。自動測試會比對這些數字跟程式裡寫的一致。

照一盤雙方合計 40 步、其中 8 次吃子、3 次將軍粗估：一般模式光是特效就有約 0.28×40＋1.4×8＋2.1×3＋2.5＋2.55 ≈ 34 秒在畫面上播；快棋模式約 0.09×40 ≈ 3.6 秒，而且不會再有任何特效蓋在棋盤上。電腦每步平均再少等約 1.7 秒。

## 4. 限制與還沒做的

- **3D 園子不做預走**：預走的標記只畫在平面棋盤上。在 3D 園子裡電腦思考時點棋盤照舊沒反應；想用預走請按「▦ 平面棋盤」。快棋模式在 3D 園子裡只縮短平面棋盤那套特效（吃子、將軍、開局），3D 場景自己的動畫（棋子跳、角色動作、入座運鏡）沒有縮短。
- **線上對局還沒有預走**：線上對局的畫面要在對局頁（09b-preload.js 的 PvpGame）加跟挑戰電腦同樣的四個掛勾（點選、畫棋盤、收到新盤面、狀態列）才做得到，這一輪沒有動那個檔，也沒有改連線程式。快棋模式的走子動畫縮短、吃子／將軍／開局特效略過，在線上對局的平面棋盤一樣有效（同一套棋盤程式）；但線上對局下完時的將死動畫是對局頁自己叫的，還沒有略過。
- **預走只能排一步**，不能一次排好幾步。
- **不能把預走排到自己的子上**（例如「對方吃了我這顆，我馬上吃回來」要等對方真的吃了才點），因為點自己的子是換選。
- 預走走出時，你的步會蓋掉電腦那一步的「上一步」標記，所以用 2.5 秒的灰色虛線補標；電腦那一步的滑動動畫也會被你的步接著蓋過去。
- 預走反應時間只量了程式邏輯；手機上重畫棋盤的時間要在實機用 pmvStats() 看。
