# 實機錄影

最後核對：2026 年 11 月 12 日。

這一頁放《象棋千秋》在真的手機上錄下來的畫面，讓沒有手機的人也能看到開場電影、3D 序局和選角實際跑起來的樣子。影片沒有剪接、沒有加速，只切成三段、轉小檔。

## 錄影資料

- 手機：iPhone 17 Pro Max（開發者自己的手機），用 iOS 內建的螢幕錄影。
- App 版本：20261112-1320（當時的正式版）。
- 錄影時間：2026 年 11 月 12 日 20:39（臺灣時間），全長 3 分 0 秒。
- 原始檔：1320×2868、每秒 60 格、HEVC，有聲音。公開版轉成 720 寬、每秒 30 格、H.264，保留聲音（背景音樂、落子聲、吃子聲）。
- 錄的是「已經玩過一次的人，開一個新旅程」：從覆蓋存檔開始，一路到選好角色、降落主場。

## 第 4 段：旁白（VoiceOver）首頁實測（11/13）

- **裝置**：同一支 iPhone 17 Pro Max（開發者本人），iOS 內建「旁白」，App 從主畫面打開，版本 20261113-0330。
- **錄影時間**：2026-11-13 04:11，全長 24 秒，沒剪接，有旁白的聲音。
- **影片**：[iphone17pm-4-voiceover-home.mp4](https://xiangqi-cdn.pages.dev/data/evidence/video/iphone17pm-4-voiceover-home.mp4)（轉成 H.264、寬 720，原檔 HEVC 1320×2868）
- **怎麼核對旁白念了什麼**：聲音用 OpenAI 語音轉文字（whisper-1，開發者同意），對照畫面上的藍色焦點框。

| 時間 | 焦點在哪 | 旁白念的（轉文字結果，簡體已還原成繁體） |
|---|---|---|
| 0～2 秒 | 小人頭上的小泡泡 | 「條碼？按鈕」（聽不清楚，轉文字可能不準） |
| 2～6 秒 | 同桌對弈 | 「同桌對弈，兩人共用這台裝置，按鈕」 |
| 6～9 秒 | 藏譜石窟 | 「**一疊書**，藏譜石窟，按鈕」 |
| 9～11 秒 | 雲河星槎 | 「**帆船**，雲河星槎，按鈕」 |
| 11～13 秒 | 觀星閣 | 「**交叉的劍**，觀星閣，按鈕」 |
| 13～17 秒 | 今日推薦 | 「**羊皮紙卷**，今日推薦，按鈕」 |
| 22 秒 | — | 「已關閉旁白」 |

**這段證明了**：首頁每個入口都選得到、焦點框清楚、念得出名字和「按鈕」。

**發現的問題（已修，跟下一版一起上線）**：
- 入口名稱前面的小圖示會被旁白念出來（帆船、交叉的劍、羊皮紙卷、一疊書），聽起來很吵。只有「同桌對弈」沒念，因為它本來就有自己的語音標籤。改成每個入口都用「去掉開頭圖示的名字」當語音標籤；「回報問題」「加到主畫面」也補上。測試：test-ui-redundancy.js。
- 焦點順序是「同桌對弈 → 藏譜石窟 → 雲河星槎 → 觀星閣 → 今日推薦」，不是由上到下，第一次用的人比較難建立位置感。這輪還沒改。

**這段沒錄到**：進一盤棋用旁白走棋、開設定——錄在第 5 段。

## 第 5 段：旁白（VoiceOver）設定頁與實際對局（11/13）

- **裝置**：同一支 iPhone 17 Pro Max（開發者本人），旁白打開，版本 20261113-0330。
- **錄影時間**：2026-11-13 04:20，全長 1 分 49 秒，沒剪接，有旁白的聲音。
- **影片**：[iphone17pm-5-voiceover-settings-game.mp4](https://xiangqi-cdn.pages.dev/data/evidence/video/iphone17pm-5-voiceover-settings-game.mp4)（轉成 H.264、寬 720）
- **怎麼核對**：聲音用 OpenAI 語音轉文字（whisper-1，開發者同意），對照畫面上的焦點框。

| 時間 | 在做什麼 | 旁白念的（摘要，簡體還原成繁體） |
|---|---|---|
| 0～21 秒 | 設定頁場景：意見回饋、修正紀錄、我的角色、試看棋盤（打開又收起） | 「意見回饋，按鈕」「修正紀錄，按鈕」「試看棋盤，按鈕」…「網頁對話，結尾」「收起，按鈕」 |
| 21～42 秒 | 雲河星槎（瀏覽器跳出「想要取用動作和方向」，按取消）→ 回首頁 | 「**帆船**…」「取消」「**西洋棋** 快速對局，不用選 **間隔號** 不算段位，按鈕」 |
| 42～71 秒 | 快速對局：3D 園子換成平面棋盤 | 「放大，按鈕」「點棋子走棋 **間隔號** 換成平面…」 |
| 71～86 秒 | 按認輸 → 確認框 → 取消 | 「認輸，按鈕」「確定認輸」「取消，按鈕」 |
| 86～99 秒 | 用旁白選子、選落點 | 「**紅方砲，二路，第三排，按鈕**」「選了紅…」「**二路，第五排，空，可以走到這裡，按鈕**」 |
| 99～108 秒 | 走出一步、電腦回一步 | 「**你走 砲二進二**」「**思考的表情** 思考」「**電腦走 象 7 進 5，輪到你**」 |

**這段證明了**：用旁白可以完整下棋——每一格都念出棋子、位置、能不能走到；走完、電腦回應都會報；認輸有確認框；設定頁每個入口選得到、面板收得起來。

**發現的問題（已修，跟下一版一起上線）**：
- 圖示被念出來：♟ 念成「西洋棋」、⛵「帆船」、🤔「思考的表情」。
- 「・」被念成「間隔號」（「不用選・不算段位」「點棋子走棋・換成平面」）。
- 修法：全頁的無障礙保險（`11b-a11y.js` 的 axmFix）——按鈕文字有圖示或「・」就自動補語音名稱（去掉圖示、・換成逗號），按鈕文字之後變了也跟著換；狀態列、播報區把圖示和・標成旁白跳過，畫面文字一字不變。測試：test-a11y-emoji.js（用假 DOM 實際跑）。
- 雲河星槎頁點進去時，瀏覽器會跳「想要取用動作和方向」的權限詢問（星槎的視差效果），旁白使用者會突然被打斷。這輪還沒改。

## 自己重現

1. 用手機打開 App（已經玩過、有存檔）。
2. 首頁 →「開新旅程」→ 選一格覆蓋。
3. 開場電影不要按「略過」，看完；黑洞序局照提示走「俥五進一」吃士將死。
4. 按「循著茶香」，看完後半段電影，點一顆星選角色。

## 還沒有的

- **減少動態版**：手機打開「減少動態效果」時，開場電影改成靜態分頁，這次沒錄。
- **加強後的落子漣漪**：20261112-1340 版把 3D 一般落子的漣漪加深加大（園子改深棕外環＋亮色內閃、停 0.8 秒），這段影片是 1320 版，還是舊的淡漣漪。
- **幀數、發熱、耗電的數字**：這段影片只有畫面，沒有量測數字。1340 版加了開發者用的「效能浮標」（開發者模式 → 🧪 開發者測試台 → 📈 效能浮標），之後實機錄影可以把幀數一起錄進畫面。
- 只錄了一支 iPhone，沒有 Android。
