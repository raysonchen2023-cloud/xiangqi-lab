# 象棋千秋 App 主程式（從 m.html 拆出來）

意見回饋 594：開發者同意照 Gemini 11/4 的建議分批拆分。目標是讓程式好改、好找，App 跑起來的內容不變。

## 怎麼組回去
- `m.html` 只剩頁面骨架：
  - `<link rel="stylesheet" href="m.css">`：主樣式，放在 `xiangqi-db/m.css`。
  - 一串 `//#include m/xx.js`：主程式，放在這個資料夾。
- `xiangqi-db/tools/mhtml.js` 的 `assemble()` 會把它們逐字塞回一個完整頁面。用到它的地方有三個：
  - 建置：`xiangqi-lab/tools/build-site.js`
  - 開發伺服器 `/m`：`xiangqi-referee.js`
  - `tools/find-brilliant.js`
- 拆分前後建出來的 `site/index.html` 逐字一樣（已比對）。所以這些檔仍然共用同一個全域範圍：在一個檔宣告的函式和常數，其他檔都看得到。順序照 `m.html` 裡 include 的順序。

## 改程式時
- 找某段字在哪個檔：`node xiangqi-db/tools/mhtml.js --find "要找的字"`。
- 看組好的完整頁面：`node xiangqi-db/tools/mhtml.js --out 某個路徑.html`。
- 存檔用 UTF-8、LF；Python 寫檔要加 `newline=""`。
- 改完跑 `node xiangqi-lab/tools/build-site.js`，它會檢查每段程式的語法。

## 之後還可以拆的
- 頁面裡少數寫在 JS 樣板字串裡的小段 `<style>`，可以搬進 m.css。
- 各檔改成真正的 ES Modules（import／export）。這一步要整理全域變數的依賴，風險較大，等前面穩定了再一檔一檔做。
